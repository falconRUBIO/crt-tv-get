# CRT TV for Fire TV

The CRT TV app for Amazon Fire TV Stick. Free direct download, no account needed.

## Download

**[Download CRT TV 0.5 (APK)](https://github.com/falconRUBIO/crt-tv-get/releases/download/v0.5/CRT-TV-0.5.apk)**

Short link for typing on a Fire Stick remote: **is.gd/crtapk**

## Install on a Fire Stick

1. On the Fire Stick home screen, find and install the **Downloader** app (orange icon, by AFTVnews) from the Amazon Appstore.
2. Open **Settings > My Fire TV > Developer Options > Install Unknown Apps** and allow **Downloader**.
3. Open **Downloader** and type: **is.gd/crtapk**
4. Press Go, then choose **Install** when the download finishes.
5. Open **CRT TV** from Your Apps & Channels.
